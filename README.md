# LogiX — Logistics Order Creation Dashboard

A modern **logistics order creation dashboard** built using **Next.js 14 App Router**, **React Hooks**, and **CSS Modules**.

The application allows users to create multi-package shipments and view a **real-time shipment preview** as order details are entered.

# Key Features

### Multi-Package Shipment Creation

Users can dynamically add or remove packages within a single shipment order.

### Real-Time Shipment Preview

The preview panel updates instantly when the user edits shipment details.

### Delivery Type Selection

Supports multiple delivery methods:

* Standard delivery
* Express delivery

### Shipment Flags

Additional shipment attributes can be applied:

* Fragile package handling
* Insurance protection

### Responsive Layout

Fully responsive interface supporting:

* Desktop
* Tablet
* Mobile devices

### Accessibility Support

Built using accessibility best practices:

* Semantic HTML
* Label associations
* ARIA roles
* Keyboard-friendly inputs

# Installation

Clone the repository:

```
git clone https://github.com/YOUR_USERNAME/logistics-dashboard.git
```

Navigate to the project folder:

```
cd logistics-dashboard
```

Install dependencies:

```
npm install
```

Start the development server:

```
npm run dev
```

Open your browser and visit:

```
http://localhost:3000
```
